# Related UI forks

Notes on this fork of `@aicolab/ui-solid`. Each row is a public fork under [SamJB123](https://github.com/SamJB123), and why it is worth keeping next to this kit.

This file does not copy their code. They stay separate repos.

## Libraries

| Fork | Why it is useful |
|---|---|
| [BlockNote](https://github.com/SamJB123/BlockNote) | A Notion-style block editor. This kit's editor path is ProseKit, so BlockNote is the reference for blocks, slash commands, and drag handles. |
| [tldraw](https://github.com/SamJB123/tldraw) | An infinite canvas. Useful when a screen needs a whiteboard beside the panels and command palette this kit already has. |
| [y-prosemirror](https://github.com/SamJB123/y-prosemirror) | Keeps a ProseMirror document in sync across people through Yjs. This kit already ships ProseKit bindings with Yjs presence, so this is that shared-editing layer. |
| [three.js](https://github.com/SamJB123/three.js) | The 3D library. Insight Bridge draws its galaxy with Three.js, and this kit supplies the chrome around that view. |
| [three-text](https://github.com/SamJB123/three-text) | Real 3D type for Three.js. Useful when a scene needs words in the world, not an HTML label on top. |
| [threejs-pom](https://github.com/SamJB123/threejs-pom) | `@promontis/threejs-pom`, a WebGPU material that gives a surface real parallax depth from ordinary PBR maps. Same WebGPU path as the galaxy. |
| [react-three-game](https://github.com/SamJB123/react-three-game) | A game loop, camera, and scene kit for react-three-fiber. Useful as a pattern book. It is React, and this kit is Solid, so the code does not drop in. |

## Apps

| Fork | Why it is useful |
|---|---|
| [convex-os](https://github.com/SamJB123/convex-os) | A Windows XP desktop as a running app. This kit already has an XP desktop entry (`./xp`). This fork is a whole shell built the same way. |
| [cal.com](https://github.com/SamJB123/cal.com) | A full scheduling product. Useful for booking screens and account flows. This kit already has a month calendar. |
| [Ghost](https://github.com/SamJB123/Ghost) | Publishing, memberships, and newsletters. Useful for reading pages and member gates. Insight Bridge is a reading surface too. |
| [chef](https://github.com/SamJB123/chef) | An AI app builder with a backend. Useful for a screen where a person describes an app and the app appears. |
| [wZed](https://github.com/SamJB123/wZed) | A web IDE. Useful for an editor workspace that runs in the browser. |
| [mykonos-island-voxels](https://github.com/SamJB123/mykonos-island-voxels) | A small browser 3D island with no bundler. Useful for a soft illustrated scene that stays light. |
| [pokebox](https://github.com/SamJB123/pokebox) | Cards drawn in Three.js that tilt with the viewer. Useful for a 3D card you can turn. |
| [weltenbauer](https://github.com/SamJB123/weltenbauer) | A terrain editor in the browser. Useful for sculpting a landscape. |
| [Universal-LPC-Spritesheet-Character-Generator](https://github.com/SamJB123/Universal-LPC-Spritesheet-Character-Generator) | A 2D character builder. Useful for a picker that assembles a figure from parts. |
| [nextjs-loves-wagtail](https://github.com/SamJB123/nextjs-loves-wagtail) | A short lesson: pages in Next.js, content in Wagtail. Useful as a map of a front end plus a CMS. |
| [loops-nextjs](https://github.com/SamJB123/loops-nextjs) | A small Next.js app wired to Loops. Useful as a form that talks to an outside service. |
| [LaunchPad](https://github.com/SamJB123/LaunchPad) | The Strapi demo. Useful as a content-admin screen. |
